# RostAgro · Приёмочная матрица сценариев (P1-аудит)

> Готовится в рамках **Задачи P1** (аудит, БЕЗ изменения кода/спецификации/данных).
> База: `origin/main` после Задачи O. Источник правил — `docs/ROSTAGRO_PRODUCT_SPEC.md`.

## Обозначения покрытия

| Знак | Значение |
|---|---|
| ✅ | покрыто движковым тестом **и** browser-e2e в блокирующем CI |
| 🟢E | покрыт движок (блокирующий CI), browser-e2e нет |
| 🟢U | покрыт browser-e2e, отдельного движкового теста нет |
| 🟠NB | тест есть, но в **non-blocking** джобе (не гейтит релиз) |
| 🔴NR | тест-файл есть в репо, но **в CI не запускается** |
| ❌ | сценарий не покрыт автоматикой |
| ⚠️ | **продуктовый пробел / дефект** (правило не определено или поведение спорное) |

Расшифровка тестов: `we`=verify-external-orders, `wc`=verify-order-control, `wi`=verify-order-issue,
`wn`=verify-order-n, `wg`=verify-group-receiving, `wp`=verify-place-group, `wcool`=verify-cooling,
`wz`=verify-zones, `ws`=verify-stock(+grouped), `wt`=verify-workflow-tasks (**блокирующий, P2**),
`wsh`=verify-work-shifts (**блокирующий, P2**), `wr`=verify-roles-s2 (**блокирующий, P2**),
`wblk`=verify-blocked-replanning (**блокирующий, P2**), `wsched`=verify-scheduler,
`wschedL`=verify-scheduler-live, `wtimer`=verify-timer-transition, `wtenant`=verify-tenant-s3,
`wapi`=verify-integration-api (**non-blocking**), `e2e`=scripts/e2e-release.mjs (блокирующий).
